# Session 3: Agent Service Hello World & Prompt Agents

## Core reading

- [Agents in Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/agents/overview) - Compare prompt agents and hosted agents, and understand the managed runtime.
- [Toolbox overview](https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/toolbox-overview) - Learn how shared tool collections provide a managed MCP endpoint.
- [How toolbox authentication works](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/tool-authentication) - Understand agent-to-toolbox access and downstream tool authentication.

## Hands-on references

- [Create a prompt agent](https://learn.microsoft.com/en-us/azure/foundry/agents/quickstarts/prompt-agent) - Create an agent from code and run a multi-turn conversation.
- [Function calling](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/function-calling) - Add a custom function and understand client-side tool execution.
- [Connect agents to MCP servers](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/model-context-protocol) - Attach a prepared MCP server and review authentication requirements.
- [Create and manage a toolbox](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/toolbox) - Configure reusable tool collections and their connections.

The hosted-agent toolbox quickstart is introduced in Session 4; this session focuses on prompt agents and the tool integration concepts.
