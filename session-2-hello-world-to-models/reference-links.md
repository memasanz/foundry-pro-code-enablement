# Session 2: Hello World to Models

## Core reading

- [Overview of Microsoft Foundry Models](https://learn.microsoft.com/en-us/azure/foundry/concepts/foundry-models-overview) - Understand the model catalog and model-selection options.
- [Deployment types for Microsoft Foundry Models](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/concepts/deployment-types) - Compare deployment options, processing locations, and capacity tradeoffs.
- [Role-based access control for Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/concepts/rbac-foundry) - Distinguish deployment-management permissions from model-invocation permissions.
- [Use Model Router](https://learn.microsoft.com/en-us/azure/foundry/openai/how-to/model-router) - Deploy and invoke Model Router, and review workload-specific routing considerations.
- [Azure AI Content Safety overview](https://learn.microsoft.com/en-us/azure/ai-services/content-safety/overview) - Understand safety capabilities and the kinds of harmful content they detect.

## Hands-on references

- [Get started with Foundry in code](https://learn.microsoft.com/en-us/azure/foundry/quickstarts/get-started-code) - Make an initial model request from code.
- [Content filtering for Azure OpenAI models](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/concepts/content-filter) - Review model input/output filtering, categories, and filtering behavior.

Check the portal version and model support noted in each article; Content Safety service APIs and model content filtering are related but distinct capabilities.
